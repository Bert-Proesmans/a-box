# a-box

| Path | Description |
| --- | --- |
| `default.nix` | Entry point: nixpkgs from `lon.nix`; builds the `updater` package set with the pointer, caches, keys and layout labels; exposes `pkgs`, `toplevel`, `updaterIso`, `installerIso`, `netboot` (with `netboot.githubRelease`), `publish`, and `tests.update`, an attrset of scenarios run as `nix-build -A tests.update.<scenario>` |
| `lon.nix` | Generated by lon: reads `lon.lock` and returns the fetched sources |
| `lon.lock` | lon lock file pinning `nixpkgs` (nixos/nixpkgs, `nixos-unstable`) |
| `configuration.nix` | NixOS configuration of the main system, identical for every install: hostname, networkd with DHCP, stateVersion |
| `layout.nix` | GPT partition names (ESP, root) shared by the main system and the updater |
| `modules/` | NixOS module for the main system; see [modules/README.md](modules/README.md) |
| `updater/` | Standalone minimal updater (kernel, initrd, UKI), its installer and boot media (ISOs, netboot); see [updater/README.md](updater/README.md) |
| `publish/` | `a-box-stage` and `a-box-upload` tools; see [publish/README.md](publish/README.md) |
| `tests/` | NixOS VM tests of the updater and their cache key pair; see [tests/README.md](tests/README.md) |
| `keys/cache.pub` | Nix binary cache public signing key `storage.proesmans.eu-1` |
| `.github/workflows/publish.yml` | GitHub Actions workflow: a build job stages the main system with `a-box-stage` and hands it as an artifact to an upload job, whose Upload step alone holds the bucket credentials and runs `a-box-upload` to the B2 cache and the pointer `nix-cache/a-box/main` |
| `.github/workflows/release.yml` | GitHub Actions workflow, manual and serialized: builds `updaterIso`, `installerIso` and `netboot.githubRelease`, collects them flat as `a-box-updater.iso`, `a-box-installer.iso`, `a-box-updater.efi` and `boot.ipxe`, force-moves the tag `latest` to the built commit and overwrites the assets of the single release `latest`, kept marked Latest because `boot.ipxe` chains `releases/latest/download/a-box-updater.efi` |
| `.gitignore` | Ignores `result*` and `/keys/*.sec` |
| `AGENTS.md` | Agent guidelines: writing, working, documentation, testing, git |
| `lsp.json` | Language server root markers for `nil`, `clangd`, `rust-analyzer` |

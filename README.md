# a-box

| Path | Description |
| --- | --- |
| `default.nix` | Entry point: nixpkgs from `lon.nix`; exposes `pkgs`, `pointerUrl`, `toplevel`, `updater`, `publish`, `tests.update` |
| `lon.nix` | Generated by lon: reads `lon.lock` and returns the fetched sources |
| `lon.lock` | lon lock file pinning `nixpkgs` (nixos/nixpkgs, `nixos-unstable`) |
| `configuration.nix` | NixOS configuration of the main system, identical for every install: hostname, networkd with DHCP, stateVersion |
| `layout.nix` | GPT partition names (ESP, root) shared by the main system and the updater |
| `modules/` | NixOS module for the main system; see [modules/README.md](modules/README.md) |
| `updater/` | Standalone minimal updater (kernel, initrd, UKI), installed on an ESP or netbooted; see [updater/README.md](updater/README.md) |
| `publish/` | `a-box-publish` tool; see [publish/README.md](publish/README.md) |
| `tests/` | NixOS VM test and its cache key pair; see [tests/README.md](tests/README.md) |
| `keys/cache.pub` | Nix binary cache public signing key `storage.proesmans.eu-1` |
| `.github/workflows/publish.yml` | GitHub Actions workflow: builds the main system, runs `a-box-publish` to the B2 cache and the `pointerUrl` path |
| `.gitignore` | Ignores `result*` and `/keys/*.sec` |
| `AGENTS.md` | Agent guidelines: writing, working, documentation, testing, git |
| `lsp.json` | Language server root markers for `nil`, `clangd`, `rust-analyzer` |

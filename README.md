# a-box

| Path | Description |
| --- | --- |
| `default.nix` | Entry point: imports `lon.nix` and `layout.nix` once and threads them through as module arguments and callPackage arguments; builds the guest image, the main system (the volatile VM host) and the `updater` package set with the pointer, caches, keys, layout names and the main system's disko format script; exposes `pkgs`, `guest`, `toplevel`, `updaterIso`, `installerIso`, `netboot` (with `netboot.githubRelease`), `publish`, and the VM tests `tests.update` (an attrset of scenarios, run as `nix-build -A tests.update.<scenario>`) and `tests.guests` (an attrset of tests, run as `nix-build -A tests.guests.<name>`) |
| `lon.nix` | Generated by lon: reads `lon.lock` and returns the fetched sources |
| `lon.lock` | lon lock file pinning `nixpkgs` (nixos/nixpkgs, `nixos-unstable`), `disko` and `preservation` |
| `configuration.nix` | NixOS configuration of the main system, identical for every install: hostname, networkd with DHCP, key-only ssh with the administrator's keys, declared users only, stateVersion |
| `layout.nix` | Names the main system, the installer and the updater agree on: GPT partition names (ESP, zram, data), the btrfs subvolumes (`@nix`, `@persistent`) and the disk placeholder of the installer's disko script |
| `modules/` | NixOS module for the main system; see [modules/README.md](modules/README.md) |
| `guest/` | Firecracker guest image defined in Nix (custom kernel, read-only erofs rootfs with a restricted store, stub echo init); see [guest/README.md](guest/README.md) |
| `updater/` | Standalone minimal updater (kernel, initrd, UKI), its installer and boot media (ISOs, netboot); see [updater/README.md](updater/README.md) |
| `publish/` | `a-box-stage` and `a-box-upload` tools; see [publish/README.md](publish/README.md) |
| `tests/` | NixOS VM tests of the updater and of the guest units, and their key pairs; see [tests/README.md](tests/README.md) |
| `keys/cache.pub` | Nix binary cache public signing key `storage.proesmans.eu-1` |
| `keys/guest-proxy-ca.pem` | Certificate of the guests' proxy CA, baked into every guest image as its only trust root; the private key never enters the repo or the store and is provisioned on the host at `/persistent/a-box/secrets/proxy-ca.pem` |
| `.github/workflows/publish.yml` | GitHub Actions workflow: a build job stages the main system with `a-box-stage` and hands it as an artifact to an upload job, whose Upload step alone holds the bucket credentials and runs `a-box-upload` to the B2 cache and the pointer `nix-cache/a-box/main` |
| `.github/workflows/release.yml` | GitHub Actions workflow, manual and serialized: builds `updaterIso`, `installerIso` and `netboot.githubRelease`, collects them flat as `a-box-updater.iso`, `a-box-installer.iso`, `a-box-updater.efi` and `boot.ipxe`, force-moves the tag `latest` to the built commit and overwrites the assets of the single release `latest`, kept marked Latest because `boot.ipxe` chains `releases/latest/download/a-box-updater.efi` |
| `.gitignore` | Ignores `result*` and `/keys/*.sec` |
| `AGENTS.md` | Agent guidelines: writing, working, documentation, testing, git |
| `lsp.json` | Language server root markers for `nil`, `clangd`, `rust-analyzer` |

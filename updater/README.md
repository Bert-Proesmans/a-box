# updater

| File | Description |
| --- | --- |
| `default.nix` | `lib.makeScope` package set of the updater, independent of the main system: holds the configuration (pointer, caches, keys, GPT partition names, the `@nix` subvolume, the main system's disko format script, generations kept, kernel params and config, firmware), the static tools, and the artifacts `kernel`, `initrd`, `uki`, `installerKernel` (plus keyboards and Hyper-V, VMware and QEMU disk, keyboard and display drivers), `installerInitrd`, `installerUki`, `iso`, `installerIso` and `netboot`, each a recipe in this directory taking the configuration and the other artifacts as inputs; the updater never changes `BootOrder` |
| `mk-script.nix` | `mkScript { src; replacements; }`: substitutes the `@placeholders@` of an initrd shell script and fails the build on any shellcheck (busybox dialect) finding; every script of the initrds goes through it |
| `initrd.nix` | Builds the updater initrd: `init.sh` as `/init`, static busybox, nix, curl, bash, efibootmgr and `nixos-install` without its bootloader step, the DHCP lease script, `nix.conf` for the configured caches, CA certificates and the configured firmware |
| `installer-initrd.nix` | Builds the installer initrd: `installer.sh` as `/init`, `a-box-install`, the updater UKI, and the main system's disko format script as a bare file (no closure) with exactly the tools it calls per disko layer (bash, busybox, sgdisk, blkid, mkfs.vfat, mkfs.btrfs, btrfs, the `udevadm` stand-in), plus lsblk and efibootmgr |
| `uki.nix` | Builds a UKI with ukify from a kernel, an initrd and `kernelParams`, with the given file name and os-release ID and PRETTY_NAME |
| `netboot.nix` | Builds the TFTP or HTTP root for netbooting the updater: the UKI and a `boot.ipxe` chaining `ukiUrl`, relative to `boot.ipxe` by default; passthru `githubRelease` is `netboot.override` with the absolute GitHub latest-release asset URL, since iPXE resolves relative URLs against GitHub's redirect target |
| `init.sh` | Initrd `/init`: DHCP (IPv4) and router advertisements (IPv6), Google Public DNS when the pointer host does not resolve, mounts the `@nix` btrfs subvolume of the data partition (zstd) at `/sysroot/nix` under a RAM `/sysroot` and the ESP at `/sysroot/boot`, both found by GPT name, installs the system named by the pointer with `nixos-install --no-bootloader` (retrying every 30 s while none is installed), prunes generations, installs systemd-boot, kernels and initrds of the kept generations on the ESP, registers systemd-boot as a firmware entry outside `BootOrder`, sets `BootNext` and reboots |
| `iso.nix` | Builds a reproducible UEFI-only hybrid image (CD or disk) whose only content is an appended ESP holding the given UKI at `/EFI/BOOT/BOOTX64.EFI` |
| `installer.sh` | Installer initrd `/init`: mounts the kernel filesystems, prints usage (`a-box-install` with and without a disk) and runs a shell; leaving the shell reboots |
| `a-box-install.sh` | `a-box-install [DISK]`: clears DISK and lays it out by running a copy of the disko format script with the disk placeholder replaced (ESP, zram partition, btrfs data partition with its subvolumes, as the main system declares), or takes a disk already laid out; then finds the ESP by GPT name and copies the updater to `\EFI\a-box\updater.efi` behind a firmware boot entry first in `BootOrder`, and to `\EFI\BOOT\BOOTX64.EFI`; never touches the data partition itself |
| `udevadm.sh` | `udevadm` stand-in for the installer, which has no udev: `trigger` recreates `/dev/disk/by-partlabel/<GPT name>` for the partitions of `$A_BOX_DISK` so that the disko script finds them, `settle` does nothing |
| `udhcpc.sh` | DHCP lease script: replaces the interface's IPv4 addresses, leaving IPv6 ones; the first lease sets the default route and DNS |
| `kernel.nix` | Builds the minimal updater kernel: `allnoconfig` plus the options the updater needs (btrfs with zstd for the nix subvolume, FAT for the ESP) and caller-supplied extra config, all built in, no modules; the build fails if an option is not honoured |
| `nix-musl-syscall.patch` | Makes nix build against musl: includes `<sys/syscall.h>` for `SYS_close_range` |
